# book_recommendation
Project with several book recommendation models (recommender_model.py) and experiment (experiment.py) evaluating them.

Also enables interactive usage. Run the Dockerfile for backend enabling the ratings and recommendation logic and frontend visualizing it.

```python
cd frontend
npm install
npm run dev
```



Data come from - https://www.kaggle.com/datasets/arashnic/book-recommendation-dataset?select=Ratings.csv

Is deployed on AWS at http://3.77.202.234/
